# 💸 BillSplitter - Smart Receipt & Expense Decoder

BillSplitter is a web application built with Streamlit and Google Gemini AI that extracts itemized details from bill receipts, calculates accurate totals (including service charges), and helps split expenses among multiple people.

## 🚀 Features
- **AI-Powered Receipt Parsing**: Uses Google Gemini to automatically read and parse bill receipts from images.
- **Smart Bill Splitting**: Calculates equal splits for any number of members.
- **Secure Configuration**: Uses Streamlit secrets for safe API credential management.
